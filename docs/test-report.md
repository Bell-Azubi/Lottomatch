# Test report — Lottomatch Live 1.0.0

One row per requirement and edge case of the brief (§5–§12, §14). Every result marked
**executed** was run on 2026-11-05 against the release tree; nothing marked executed was
reasoned about only.

- **Environment**: Linux container, Node.js 26.13.0, npm 11.20.0; Playwright 1.63.0 with its
  Chromium build 1243 (headless, software rendering); Lighthouse 13.6.0 through `@lhci/cli`
  0.16.0; production build with `BASE_PATH=/Lottomatch/` and
  `SITE_URL=https://bell-azubi.github.io/Lottomatch/`.
- **Executed**: ran here, with the result shown.
- **Mental run**: traced through the code and its tests; not executed as an end-to-end check.
- **Not executed**: could not run in this environment; the CI job named in the row runs it.
